## What's new

v2.16.1 is a **bug-fix release** addressing two token-display and token-refresh issues on the desktop app. No new features, no on-disk, CLI, or IPC changes — upgrade is drop-in.

### Tokens no longer risk going stale across laptop sleep (PR #712)

The background token refresher waited between cycles using a single monotonic timer. On macOS that timer pauses while the host sleeps, but OAuth tokens keep aging on the real-world clock — so a long laptop sleep could leave a token un-refreshed (even briefly expired) for up to a full cycle after wake. The refresher now also watches the wall clock and catches up within ~30 seconds of wake, while keeping the original steady-state cadence and its immunity to backward clock changes.

### The "Expires 1h" badge now shows a live countdown (PRs #709, #712)

Two fixes to the per-account token badge:

- The badge previously floored the entire final two-hour window to a static "1h", which read as a stuck token. It now shows a live minute countdown ("119m" → "60m") through that window, rolling over to "2h" at the boundary.
- The badge's warning threshold was decoupled from the daemon's 2-hour refresh trigger, removing the "many accounts say Expires 1h" false alarm where healthy, actively-refreshing accounts looked like they were about to expire.

## Compatibility notes

- No on-disk layout, CLI flag, IPC, or `csq doctor` schema changes. Upgrade is drop-in from v2.16.0.
- Desktop auto-update applies normally for users already on a Developer-ID-signed stable build.
