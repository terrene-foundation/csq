# csq v2.14.0

**Release date:** 2026-05-27

## What's new

The distribution cut. Two release-infrastructure features that landed on `main` after v2.13.1 take effect with this release: **Intel Mac desktop auto-update** and **Homebrew CLI distribution**. Both are exercised end-to-end for the first time by this very tag.

### Added

#### Intel Mac desktop auto-update via universal binary (an internal ticket)

Apple Silicon **and** Intel Mac desktop users can now both auto-update through `tauri-plugin-updater`. The macOS desktop bundle is built with `--target universal-apple-darwin` — one `.app` carries a fat Mach-O with both arm64 and x86_64 slices, signed and notarized once.

`latest.json::platforms` emits **both** `darwin-aarch64` and `darwin-x86_64` keys pointing at the same universal `.app.tar.gz` with the same minisign signature. Gatekeeper's "same Team ID across updates" rule is structurally satisfied — one signed artifact = one Team ID = both arches. This closes the Intel auto-update gap where `latest.json` previously carried no `darwin-x86_64` key, leaving Intel desktop users unable to receive in-app updates.

New `specs/14-release-artifact-contract.md` captures the universal-binary invariant (INV-02), the `latest.json` schema, and the stable-vs-prerelease signing-flow split.

**Trade-off:** the macOS updater tarball grows ~9 MB → ~15 MB (Apple Silicon users pay the x86_64 slice once per release); the macOS build step runs ~20–30% longer. Both stay within the release-time budget.

#### Homebrew tap CLI distribution (an internal ticket, closes #583)

`brew tap terrene-foundation/csq && brew install csq` installs the csq CLI on macOS (aarch64 / x86_64) and Linux (x86_64). The release workflow now auto-bumps the tap formula on every **stable** release, so `brew upgrade csq` tracks new versions with no manual step. Pre-releases are excluded — they never become the default `brew install`.

### Internal

- The stable-release macOS signing flow now builds, signs, notarizes, and staples the **universal** `.app` locally per `docs/release-signing.md` §1–§8 before the tag push; CI validates the maintainer-supplied artifacts and fails closed if absent.
- Workspace housekeeping merged since v2.13.1: `an internal workspace` CLOSEOUT, the 2026-05-27 PM sweep, and journal MUST Rule 8 (converged workspaces move their `todos/active/00-index.md` to `completed/`).
- **macOS auto-updater trust chain unchanged** — Developer ID signed + notarized + stapled; minisign pubkey `F1C2F7FD79F952DD` (since v2.7.0).

### Upgrade notes

- **Intel Mac desktop users:** this is the first release your in-app updater can fetch. Existing Intel installs that pre-date the universal binary may need a one-time manual re-download of the notarized DMG; subsequent updates are automatic. See `docs/release-signing.md` §8b for the ad-hoc → Developer-ID one-time reinstall guidance.
- **Apple Silicon desktop users:** auto-update from v2.13.1 propagates this cut. No action required.
- **CLI users:** existing install methods are unchanged; `brew install csq` via the tap is now an additional option.
- No on-disk migration. No credential changes.
