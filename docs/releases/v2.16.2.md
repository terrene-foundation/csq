# csq v2.16.2

**Release date:** 2026-06-16
**Prior release:** v2.16.1 (2026-06-13)
**Checksum / signature:** see artifact `SHA256SUMS` and `.sig` files on the GitHub Releases page.

## What's new

v2.16.2 is an **infrastructure release** that re-establishes the community edition's home repository and restores the auto-update channel. There are **no functional code changes** from v2.16.1 — the binary behaves identically; upgrade is drop-in.

### Auto-update channel restored

The community edition's repository was reorganized, which temporarily left the auto-updater (which polls `terrene-foundation/csq` for `updater-manifest/latest.json`) unable to reach a published manifest. This release republishes the community edition to its public home at `terrene-foundation/csq` and restores the rolling updater manifest, so `csq update install` and the desktop auto-updater work normally again.

If your client reported update-check failures since the reorganization, they resolve with this release.

## Compatibility notes

- No on-disk layout, CLI flag, IPC, or `csq doctor` schema changes. Upgrade is drop-in from v2.16.1.
- Artifacts are signed with the same Foundation Ed25519 (CLI) and minisign (desktop, key `F1C2F7FD79F952DD`) keys shipped clients already trust — signature verification is unaffected.
- The community edition is Apache-2.0, Terrene Foundation-owned. It is published from the commercial upstream via a one-way extraction; the enterprise direct-API surface is not part of this edition.
